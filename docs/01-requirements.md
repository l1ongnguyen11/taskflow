# TaskFlow - Software Requirement Specification (SRS)

## 1. Project Overview

TaskFlow is a collaborative project management platform inspired by Jira. It helps teams organize projects, manage tasks, collaborate efficiently, and track project progress through Kanban boards.

## 2. Objectives

- Manage workspaces
- Manage projects
- Manage tasks
- Track project progress
- Improve team collaboration

## 3. Target Users

- Software development teams
- Startups
- Small businesses
- Students working in teams
